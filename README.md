## 🚀 How to Use

### Step 1: Enable Macros
1. Download file from link above
2. Open in Microsoft Excel
3. Click "Enable Macros" when prompted
4. Dashboard features now active

### Step 2: View Dashboard
1. Go to **"Dashboard"** sheet (opens by default)
2. See Total Revenue overview
3. View Monthly Revenue trend
4. Check Yearly Comparison
5. Analyze Flat Revenue breakdown
6. Use Status filters (Active/Over)

### Step 3: Check Payment History
1. Go to **"Table Chat"** sheet
2. View tenant monthly payments
3. Filter by tenant or flat
4. Check payment amounts
5. Review grand totals
6. Verify payment status

### Step 4: Add Payment Data
1. Go to **"Payment DATA"** sheet
2. Enter new payment records:
   - Tenant name
   - Flat number
   - Payment date (Year/Month)
   - Amount paid
3. Save & refresh dashboard
4. Payment auto-calculates to charts

### Step 5: Manage Rental Details
1. Go to **"Rented Details"** sheet
2. Add new tenant information:
   - Tenant name
   - Flat assignment
   - Lease start date
   - Lease end date
   - Deposit amount
   - Tenure information
3. Mark status (Active/Over)
4. Auto-updates dashboard

### Step 6: Track Electricity
1. Go to **"Electricity Reading DATA"** sheet
2. Enter monthly readings:
   - Date/Month
   - Previous reading
   - Current reading
   - Units consumed
   - Bill amount
   - Tenant reference
3. Track consumption trends

### Step 7: Update Owner Info
1. Go to **"Owner Details"** sheet
2. Add/update owner information:
   - Owner name
   - Properties owned
   - Contact details
   - Bank account info
   - Payment preferences
3. Tracks owner portfolio

### Step 8: Refresh Dashboard
1. Click **"Refresh"** button
2. All data updates instantly
3. Charts recalculate
4. Totals verify
5. Status filters refresh

## 🔧 Customization

### Add New Property:
1. Go "Rented Details" sheet
2. Add property/flat number
3. Assign to owner
4. Set lease terms
5. Mark status
6. Auto-appears in dashboard

### Add New Tenant:
1. "Rented Details" → New row
2. Enter tenant name, flat, dates
3. Set deposit & tenure
4. Mark as Active
5. Dashboard updates

### Track New Payments:
1. "Payment DATA" → New entry
2. Enter tenant, flat, amount, date
3. Save & refresh
4. Appears in monthly chart
5. Updates totals

### Configure Validation:
1. "Validation" sheet
2. Update status types
3. Add payment categories
4. Modify filters
5. Applies to all sheets
